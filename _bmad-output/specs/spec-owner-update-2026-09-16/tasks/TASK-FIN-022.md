## Пункты задачи

- [ ] **REQ-FIN-007.01** — Персональный расчёт собирает средний чек основной услуги, ключевую услугу, город, формат онлайн/очно/смешанный, намерение работать индивидуально/с группами и другие утверждённые параметры деятельности.
  - Проверка: Quote request валидирует обязательные поля и возвращает объяснимые входные факторы.

- [ ] **REQ-FIN-007.02** — Если остаются надбавки +5000 за город-миллионник и +3000 за только онлайн, утвердить закрытый список 16 городов и нормализацию написаний, а также разрешено ли суммировать надбавки.
  - Проверка: Тесты на вариант написания каждого города и комбинацию online+million дают утверждённый результат.

- [ ] **REQ-FIN-007.03** — Если сохраняется скидка −1000 для базового тарифа при среднем чеке <3000, определить источник/период среднего чека и закрытый перечень низкочековых услуг; «массаж, т-игра, рисование и подобное» нельзя исполнять как открытый критерий.
  - Проверка: Классификатор услуг закрыт, а boundary 2999/3000 ₽ проверен.

- [ ] **REQ-FIN-008.01** — Старые варианты цены не объединяются: база 12000 и Эксклюзив 20000 с setup 3000; график входа 8000/9000/10000/12000 на дни 1–7/8–14/15–21/22+; V3 10000/11000/12000/13000/14000 и Эксклюзив 16000→20000; ориентиры 8000–15000 и 16000–20000; действующая V2 фиксирована 3900/5900/9990. Ранняя недельная скидка от базы 12000: −4000/−3000/−2000/0 по окнам 1–7/8–14/15–21/22+ дней (эквивалентно 8/9/10/12 тыс.).
  - Проверка: Decision выбирает одну новую versioned policy либо сохраняет V2; исторические правила не становятся активными неявно.

- [ ] **REQ-FIN-008.02** — Первое подключение может требовать setup fee 3000 ₽, а обновление карточки включаться в абонентскую плату; определить, для каких категорий и policy version это применимо.
  - Проверка: Invoice явно разделяет setup и recurring line items.

- [ ] **REQ-FIN-008.03** — Подтверждённая цена фиксируется на непрерывное резидентство; при перерыве более 3 месяцев она пересчитывается по актуальной политике. Резидентство предоплачивается фиксированной суммой за один месяц/не более 30 календарных дней; link продления предлагается за 3–5 дней.
  - Проверка: Order не позволяет купить более 30 календарных дней вперёд; тест на 3 месяца перерыва подтверждает выбранную границу перерасчёта.

- [ ] **REQ-FIN-008.04** — Порог «Эксклюзив» от цены услуги 15000 ₽ должен быть объявлен строгим eligibility rule либо только маркетинговой рекомендацией.
  - Проверка: API и контент одинаково обрабатывают услугу стоимостью 14999 и 15000 ₽.

- [ ] **REQ-FIN-009.01** — Эквивалентные записи одной шкалы «Энергии начала» объединены: скидки 40%/30%/20%/0% означают коэффициенты оплаты 0.6/0.7/0.8/1 для эксперта/центра/организатора; для аренды 20%/10%/0% означают 0.8/0.9/1. Начало отсчёта — calculation_timestamp. Точные переходы этапов определяются DEC-FIN-010.
  - Проверка: Boundary-тесты на дни 3/4/6/7/9/10 и time zone возвращают утверждённые коэффициенты.

- [ ] **REQ-FIN-009.02** — Для одинаковой шкалы сохраняются варианты границ: календарные «первые 3 дня / дни 4–6 / дни 7–9 / после 9» и псевдокод floor(elapsed_days) с <=3/<=6/<=9. Выбрать часовой пояс, начало дня, включительность границы и поведение повторного расчёта; после окна аренды 6 дней исходный псевдокод задаёт коэффициент 1, короткая оферта об этом умалчивает.
  - Проверка: Decision называет единственную активную таблицу, а документация маркирует альтернативу superseded.

- [ ] **REQ-FIN-009.03** — После акции цена вычисляется по актуальной policy; критерий «новый привлечённый эксперт», который уменьшает цену центра/организатора, определяется отдельно.
  - Проверка: Technical design определяет qualified referral и event, после которого пересчитывается quote.

- [ ] **REQ-FIN-010.01** — Трёхмесячный «Старт» является предоплатой размещения за 3 месяца; предложенная формула умножает месячный quote на 3 и применяет дополнительный коэффициент 0.85 в первом окне и 0.90 во втором разрешённом окне.
  - Проверка: Тесты первого, второго и позднего окна проверяют доступность и коэффициент 0.85/0.90/без скидки.

- [ ] **REQ-FIN-010.02** — После всех скидок месячная цена каждой категории не ниже 5000 ₽; при достижении floor дополнительная скидка «Старт» не применяется. Порядок floor, акции, трёхмесячной скидки и бонусного списания фиксируется.
  - Проверка: Quote ниже 5000 поднимается до 5000 и не получает дополнительную скидку Start.

- [ ] **REQ-FIN-010.03** — «2 месяца по цене 1» — отдельная акционная механика: при is_promo_active и действующей дате окончания месячная оплата продлевает subscription_end_date на 60 дней; её совместимость с Energy Start и Start решается отдельно.
  - Проверка: Тест inactive/expired promo не продлевает на 60 дней.

- [ ] **REQ-FIN-007.04** — Изменение сведений эксперта запускает проверку менеджером и пересчёт персонального тарифа по актуальным проверенным данным. Для намеренно искажённых/скрытых сведений процедура, доказательства, уведомление, обжалование и срок проверки закрываются DEC-FIN-024; автоматическое ретроактивное взыскание не задано исходником.
  - Проверка: Изменённые факторы создают новый запрос проверки и новый снимок расчёта, сохраняя прежние значения и аудит менеджера.
  - Проверка: Два одинаковых события изменения не создают два ценовых предложения.
  - Проверка: Без подтверждённого правила DEC-FIN-024 обвинение в недостоверности не приводит к автоматическому дополнительному списанию.
