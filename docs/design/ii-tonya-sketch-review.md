# ии-Тоня — протокол просмотра эскизов и выбора владельца

REQ-EXP-019 · TASK-EXP-019. Каркас для обязательного шага приёмки: «3–5 эскизов, предъявить
владельцу и зафиксировать выбор перед финальной отрисовкой, **без самовольного выбора
окончательного варианта**» (критерии EXP-019, шаг 2–4). Заполняется владельцем/дизайнером;
исполнитель **не** отмечает финальный вариант.

## Статус

- Эскизы подготовлены дизайнером: ☐ нет ☐ да (дата: ______, число эскизов: ___)
- Выбор владельца зафиксирован: ☐ нет ☐ да (id эскиза: ______, дата: ______, ответственный: ______)
- Финальная отрисовка знака + 8 поз: ☐ не начиналась (ждёт выбор выше + DEC-EXP-005 по палитре)

Без отмеченного «выбор владельца» EXP-019 не переходит к финальной отрисовке и не закрывается.

  палитры — после DEC-EXP-005.
