# Клиентский каталог пакетов

Зафиксировано решениями. Цены — владелец 2026-09-17: 4999 / 5999 / 7999 / 10990 ₽.

## Решения

- DEC-FIN-002 ②: срок платных пакетов = **60 календарных дней**; intro «Знакомство» = **100** сообщений (текущая схема, без ретро-обрезки).
- DEC-FIN-003 ②: купоны при покупке = **только x2** от оплаты; `cash+credit=price`; фиксированные гранты 1000/2000/3000/4000 **не храним**.
- DEC-FIN-001 B: новые клиенты → будущая платная versioned policy, не `free_client_v2`.

## SKU

| SKU | Units | Срок | Price ₽ | `price_minor` | Coupon grant ₽ (x2, 1:1 ₽) |
|---|---:|---|---:|---:|---:|
| Знакомство (intro) | 100 | нет expiresAt | не продаётся | — | 0 |
| Старт | 500 | 60д | 4999 | 499900 | 9998 |
| Базовый | 1000 | 60д | 5999 | 599900 | 11998 |
| Глубокий | 1500 | 60д | 7999 | 799900 | 15998 |
| Максимальный | 2000 | 60д | 10990 | 1099000 | 21980 |

Купонный грант = `2 × price` (DEC-FIN-003 ②). Фиксированные 1000/2000/3000/4000 не хранятся. Оплата пакета: `cash + credit = price`. Начисление купонов в runtime V2 по-прежнему default-off до TASK-FIN-021.

`expiresAt` платного SKU = `paid_at + 60 calendar days` (срок принят DEC-FIN-002, где явно сказано, что 30-дневное истечение ЭТИМ решением не задано). **Часовой пояс закрыт вердиктом владельца 2026-09-21: GMT+3** — постоянное смещение UTC+3, DST в РФ с 2014 нет; совпадает с действующим default `DISPLAY_TIMEZONE=Europe/Moscow`, `packages/config/src/env.ts:186` — проверено). Запись: `.memlog.md` (decision by user). Реализационное следствие для `TASK-FIN-021`: календарные 60 дней считаются по границам дня в UTC+3, хранение timestamp остаётся UTC (хост и БД идут в UTC). **Не закрыто этим документом:** вторая половина Q-169 — опорный момент (`paid_at` против `granted_at`) и историческая совместимость отсчёта; отсчёт от `paid_at` вместо `granted_at` историческую совместимость не описывает; наконец уже отлитый путь `admin`-грантов истекает по другому правилу — `packages/db/src/repositories/admin-repository.ts:369` `case when kind='admin' then db_now + interval '30 days'` — проверено 2026-09-21, то есть 30 и 60 дней живут в коде одновременно и требуют сверки в `TASK-FIN-021`.
