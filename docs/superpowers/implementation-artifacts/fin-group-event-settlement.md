# Settlement группового мероприятия

DEC-FIN-013 **①**: депозит **30% стоимости услуги проекта** (не «предполагаемой выручки»). DEC-FIN-020 **①**: карточка события входит в лимит одной включённой группы базового резидента.

## Резидент vs нерезидент

- Базовый резидент: индивидуальные услуги без лимита + **одна** включённая группа/период (карточка = расход единицы).
- Дополнительная группа резидента: 10% расчётной выручки.
- Нерезидент: только набор группы, 15% выручки + 4500 ₽ карточки. Включённой группы нет.

## Деньги

1. Заявка: бронь **30% цены услуги проекта** (post-discount, как FIN-017).
2. После набора: **70% остаток**.
3. Отчёт — по **зарегистрированным** участникам.
4. Счёт: **5 рабочих дней**.
5. Набор **не гарантирован**. Conservation: `deposit + remainder = project_service_price`.

Отмена/недобор: депозит и остаток не выдумываются здесь как refund — FIN-025. Пока `PAYMENTS_ENABLED=false`.
