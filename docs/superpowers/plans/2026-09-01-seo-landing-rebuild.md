# SEO Landing Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выпустить индексируемый, быстрый и доступный лендинг ии-Тони по контракту `seo-landing` v1.11 без потери действующего контента, аналитики и юридических маршрутов.

**Architecture:** Vite на этапе сборки внедряет результат `renderLanding()` в `index.html`; браузерный TypeScript становится progressive enhancement и не создаёт основной DOM. SEO metadata и JSON-LD находятся в HTML shell, а публичные crawlability-файлы копируются из `public/`.

**Tech Stack:** Vite 7, TypeScript 5.8, Vitest 3, semantic HTML, CSS, local AVIF/WebP/PNG assets.

**Spec:** `docs/superpowers/specs/2026-09-01-seo-landing-rebuild-design.md`
