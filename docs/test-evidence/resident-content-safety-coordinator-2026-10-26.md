content does not. A replay must remain rejected without extra incidents. Direct SQL
rejection can roll back the SQL transaction; application rejection must deliberately
commit its minimal outcome. No raw rejected text in security telemetry or incidents.

current policy locking preventing approval/publication races. Manager warnings require
reviewable source fields and explicit current acknowledgment under normal authority.

or corrupt active policy denies gated work. Unsupported syntax and oversized inputs
must fail within explicit budgets rather than reach a backtracking engine. Inspect
normal composition, imports/manual fallback, privacy deletion and actual publication
entrypoints, including the latest replacement SQL functions rather than old copies.
